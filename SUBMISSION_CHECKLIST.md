# Submission checklist

For each of the 10 case studies:
- [ ] Read and confirm the problem statement and assumptions with your instructor.
- [ ] Run `main.py` in Python 3.
- [ ] Try all listed test cases.
- [ ] Capture your own output screenshot if required.
- [ ] Review the algorithm, flowchart, pseudocode, and conclusion.
- [ ] Add your name, roll number, class, and date if your college format requires them.
- [ ] Upload the final work to your GitHub repository named `PythonActivity-Based-Learning`.

Do not submit sample assumptions without checking whether they match your faculty's instructions.
