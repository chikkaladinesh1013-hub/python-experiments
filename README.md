# Python Activity-Based Learning — 10 Case Studies

This ZIP contains 10 complete beginner-level Python case-study folders selected from the supplied assignment list.

## Selected case studies
1. University Scholarship Allocation
2. Progressive Electricity Billing
3. Employee Payroll and Deduction Analysis
4. Retail Billing with Multiple Discount Rules
5. Examination Result and Grace-Mark Validation
6. ATM Transaction Sequence Simulation
7. Student Timetable Conflict Detection
8. Nested Loop Examination Seating Generator
9. Student Marks Matrix Analysis
10. Tuple-Based Product Catalogue Audit

## Contents of each case-study folder
- `01_Problem_and_Objectives.md` — problem statement, objectives, assumptions and rules
- `02_Algorithm.md` — step-by-step algorithm
- `03_Flowchart.md` — Mermaid flowchart source
- `04_Pseudocode.md` — pseudocode
- `main.py` — complete Python program
- `05_Test_Cases.md` — sample test cases and expected results
- `06_Sample_Output.txt` — illustrative console output
- `07_Conclusion.md` — conclusion
- `08_Sample_Output_Screenshot.png` — image of the illustrative output

## How to run
1. Extract the ZIP file.
2. Open a case-study folder in VS Code, IDLE, or another Python editor.
3. Run `main.py` using Python 3:
   `python main.py`
4. Enter the values requested by the program.

## Important notes
- The assignment asks for output screenshots. The PNGs included here are sample-output illustrations, not screenshots captured from your own computer. Run each program and capture your own execution screenshot if your instructor requires proof of your run.
- Flowcharts are provided as Mermaid source in Markdown. You can view them in a Mermaid-compatible Markdown preview or redraw them neatly in your practical record.
- The rules and thresholds are explicit project assumptions for these sample solutions. If your teacher supplies different values, update the assumptions and corresponding code.
- These are local project files. They have not been uploaded to GitHub. Create a repository named `PythonActivity-Based-Learning` and upload the extracted project folder yourself, or use GitHub Desktop.
